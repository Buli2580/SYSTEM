ACCOUNT DELETION // SYSTEM

Usuwanie konta SYSTEM.

Użytkownik może zażądać usunięcia konta SYSTEM CLOUD i powiązanych z nim danych bezpośrednio w aplikacji.

Jak wysłać żądanie

  1. Otwórz aplikację SYSTEM.
  2. Przejdź do SYSTEM ONLINE.
  3. Otwórz sekcję Prywatność i konto.
  4. Wybierz Zażądaj usunięcia konta.
  5. Potwierdź żądanie w aplikacji.

Jakie dane obejmuje żądanie

Żądanie dotyczy konta SYSTEM CLOUD oraz danych powiązanych z tym kontem, w tym profilu i danych synchronizowanych do chmury. Dane lokalne zapisane wyłącznie na urządzeniu można usunąć osobno z poziomu ustawień aplikacji lub przez wyczyszczenie danych aplikacji.

Okres realizacji

Żądanie jest rejestrowane po jego potwierdzeniu. Dane mogą być przechowywane przez ograniczony czas, jeśli jest to konieczne do bezpieczeństwa, obsługi nadużyć, rozliczenia żądania lub spełnienia obowiązków prawnych.
